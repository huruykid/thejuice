## Goal

Ship one new SEO pillar blog post: **"Anonymous Dating Reviews — How It Works"**. Conversion-first, SEO-optimized, brand-voice compliant. No edits to existing posts.

## Why this angle

- Matches our `/anonymous-dating-reviews` landing page → reinforces the keyword cluster instead of cannibalizing it.
- "Anonymous dating reviews" is a low-competition, high-intent term — searchers are mid-funnel (curious how it works, evaluating trust).
- Pillar format = long-form, internally links to `HowItWorks`, `AnonymousDatingReviews`, `TeaAppComparison`, individual story examples. Compounds SEO across the site.

## Step 1 — UX copy agent drafts the post

Spawn a read-only `acp_subagent` with a UX copywriter system prompt. Deliverables:

1. **Title** (≤60 chars, keyword-first, click-worthy)
2. **Slug** (kebab-case, keyword-anchored)
3. **Meta description** (≤155 chars, conversion hook + keyword)
4. **Excerpt** (1–2 sentences for blog index card)
5. **Keywords array** (5–8 terms; primary + LSI)
6. **Read time** (minutes, integer)
7. **Body** (Markdown, ~1,200–1,800 words) with this structure:
   - Hook paragraph (problem men face when researching a match)
   - "What is an anonymous dating review?" (definition + why it matters)
   - "How Juice's anonymous reviews work" (4-rating-metric system, manual approval, no phone retention, no location)
   - "Why anonymous beats public dating reviews" (safety, honesty, legal)
   - "How to write a useful review" (codename, specificity, no doxxing)
   - "How to read a review" (red flags, patterns, ratings interpretation)
   - FAQ section (5 Q&A — fuels FAQPage JSON-LD potential later)
   - CTA block linking to request access
8. **Internal link map**: which anchor text → which route (`/how-it-works`, `/anonymous-dating-reviews`, `/tea-app-comparison`, `/men-dating-community`).

**Brand voice constraints** (enforced in agent prompt):
- Men-only, anonymous, story-driven
- No "guys/bro", no fake urgency, no fabricated stats
- Respect privacy memory: no invite codes, no location, no phone retention
- Flesch grade ≤ 8, short paragraphs, scannable H2/H3
